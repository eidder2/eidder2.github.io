🚀 What Is bonsai2-small-gpu?

In simple terms, bonsai2-small-gpu is a performance-optimized launcher and runtime environment for running the Bonsai 2 27B large language model (LLM). It's designed to deliver high-quality AI responses while using much less GPU memory than standard tools. The name "small-gpu" is the whole point: it works on GPUs with limited VRAM, which most people own.

This project contains three major innovations:

  • Ternary quantization — a smart way to compress the model to 1.5 bits per weight, dramatically reducing memory usage without significant loss in quality.
  • A 1.5x faster decode kernel for PrismML — the engine that generates text is optimized to work 50% faster.
  • Qwen 3.8 MTP head — a special "multi-token prediction" head that enhances the quality and speed of your outputs.
  • Performance sweeps by PR — continuous tuning ensures you get the best possible performance on various GPU models.

❓ Frequently Asked Questions

🤔 Why does it work on smaller GPUs?

Because it uses "ternary" weights — this means each number in the model is stored with only 1.5 bits instead of the usual 16 bits. That's roughly 10 times less memory needed.

⚡ How fast will it be?

On an RTX 3060, expect around 15-20 tokens per second. On an RTX 4090, you can hit 40+ tokens. The speed sweep feature automatically finds the fastest stable setting for you.

📝 Is this safe to run?

Yes. This is an open-source project. The code is publicly viewable on GitHub. No system-level changes are made — it runs standalone.

🔧 What if the app doesn't start?

Make sure you have an up-to-date NVIDIA driver. If you still have issues, check the "Issues" tab on the GitHub page for existing solutions or ask for help there.

🧠 Why "bonsai2-small-gpu"?

The name comes from the project's philosophy: "Bonsai" suggests something small but perfectly formed — the model is compact yet mighty. "Small-gpu" is a direct nod to the goal: making 27B models usable on ordinary GPUs. It's a bold claim, but the project delivers exactly that.

🔬 Technical Highlights (For the Curious)

If you're interested in how this works under the hood, here's a snapshot:

  • Ternary Weights: The 27B model is compressed using ternary quantization, where each weight is -1, 0, or +1, requiring only 1.5 bits per weight.
  • PrismML Kernel: The custom decode kernel leverages memory layout optimizations and low-level CUDA tricks to boost throughput.
  • Qwen 3.8 MTP Head: Multi-token prediction (MTP) allows the model to "predict ahead" and improve accuracy and speed.
  • PR Sweeps: The project includes automated pull-request benchmarks that continuously finetune settings for many GPU types.
